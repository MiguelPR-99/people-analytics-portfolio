# Abrir el reporte en Power BI Desktop

[← Volver al caso](../README.md) · [English](power-bi-fast-track.en.md)

1. [Abre la página del archivo PBIX en GitHub](https://github.com/MiguelPR-99/people-analytics-portfolio/blob/main/projects/talent-review-calibration/power-bi/Project-0-Talent-Review-Calibration.pbix).
2. Selecciona **Download raw file** para descargarlo.
3. Abre el archivo en **Power BI Desktop para Windows** y explora las páginas y sus filtros.

El archivo incluye los datos guardados de la demostración; no necesitas actualizarlos para explorarlo.

[Instalar Power BI Desktop](https://learn.microsoft.com/power-bi/fundamentals/desktop-get-the-desktop)
