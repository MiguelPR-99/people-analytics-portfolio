# Open the report in Power BI Desktop

[← Back to the case](../README.en.md) · [Español](power-bi-fast-track.md)

1. [Open the PBIX file page on GitHub](https://github.com/MiguelPR-99/people-analytics-portfolio/blob/main/projects/hr-services-control-tower/power-bi/Project-1-HR-Services-Control-Tower.pbix).
2. Select **Download raw file** to download it.
3. Open the file in **Power BI Desktop for Windows** and explore its pages and filters.

The file includes the demonstration's saved data; you do not need to refresh it to explore the report.

[Install Power BI Desktop](https://learn.microsoft.com/power-bi/fundamentals/desktop-get-the-desktop)
