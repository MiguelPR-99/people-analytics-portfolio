## The problem

Someone wants to know how to add a dependent to their benefits. They may find the answer in a policy, but they may also need to submit a request and understand what happens next.

I developed this project to connect both steps: look up the available information and create a ticket with the required details after the user confirms.

## End-to-end demonstration

The walkthrough shows a benefits question, an answer with its source, and request creation. The agent displays a summary, waits for confirmation, and returns the ticket number generated by Power Automate. The record is stored in Microsoft Lists.

## How it works

1. **Copilot Studio searches four synthetic PDFs.** It answers with the policy and section used. If it cannot find enough information, it acknowledges the gap and offers HR follow-up.
2. **The agent prepares the request.** It collects a brief summary and synthetic contact details, shows what will be recorded, and waits for confirmation in a later message.
3. **Power Automate creates the ticket.** It validates the service against the catalog, calculates target dates, and stores the request in Microsoft Lists. The agent displays the ticket number and the details returned by the flow.

## Key decisions

I separated consent to be contacted from authorization to create the ticket. If the user changes the details, the agent must show a new summary and ask for confirmation again.

I also configured instructions to refuse requests for restricted personal information and offer a human-review request for sensitive matters. The published examples show this behavior.

## Development and testing

I evaluated fifteen questions covering policies, missing information, privacy, and language. These tests check individual answers; the demonstration separately shows the conversation and ticket creation.

During evaluation, a duplicate OneDrive source prompted for an additional connection. Removing it and keeping the directly uploaded PDFs allowed retrieval to use the intended sources. I also adjusted the language instructions and the bilingual question in the test set.

The project helped me work with an agent's knowledge sources, define when it can act, and interpret what evaluation results actually mean.
